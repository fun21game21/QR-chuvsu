# Соответствие требованиям QR-CHUVSU v2

Источники требований: запрос заказчика, QR_CHUVSU.pptx (включая заметки и скриншоты), QR_CHUVSU.pdf, Материал_для_защиты_QR_CHUVSU.docx. Описание старой реализации учитывается как спецификация продукта; советы для выступления не являются инструкциями разработчику.

| Требование | Реализация |
| --- | --- |
| Название и концепция | QR-CHUVSU v2, браузерная отметка студентов |
| QR-сессия и шестизначный код | `routers/sessions.py`, `services/qr_generator.py` |
| ФИО, группа, мобильная форма | `templates/student.html`, `static/app.js` |
| Активность и срок | `services/attendance.py`, повторная проверка при отправке |
| Cookie UUID | `services/security.py`, подписанная HttpOnly cookie |
| Fingerprint | JS: UA, язык, timezone, экран; на сервере SHA-256 |
| Геолокация и Haversine | HTML5 API, серверный расчёт метров |
| Повтор ФИО/группы и устройства | Транзакция и частичные уникальные индексы |
| IP-антиспам | Общий PostgreSQL-счётчик, дополнительный предел в Nginx |
| Отклонённые попытки с причиной | `attendance`, панель, отдельный лист Excel |
| Панель преподавателя | `/teacher/session/{id}`, владение через cookie без аккаунтов |
| Ручная отметка | Только создатель, отдельный статус, без требования GPS |
| Закрытие и возврат к сессии | Кнопка закрытия, список активных занятий создателя |
| Расписание звонков | `schedule.json`, раскрываемый блок; демонстрационные часы явно обозначены |
| Преподаватель и место | Преподаватель, выбор корпуса ЧГУ из справочника; отображение в панели и форме студента |
| Группировка по группам | Журнал, сортировка Excel; ручные записи допускают другую группу |
| Excel | ФИО, группа, дата, время, статус, причина; текст не становится формулой |
| PostgreSQL без ORM | asyncpg, параметризованный SQL, миграции |
| Docker и Nginx | Compose, healthchecks, постоянные тома |
| HTTPS для телефона | Отдельная инструкция и необязательный override; внешних изменений нет |
| GitHub | README, MIT, CI, тесты, `.env.example`, `.gitignore` |

## Принятые ограничения

- Сессия задаёт одну группу; справочник списочного состава не добавлен. В старой защите полноценные списки групп и семестровый журнал указаны как дальнейшее развитие.
- Нет регистрации, логина, пароля, личного кабинета или восстановления доступа.
- Cookie — право управления в одном браузере, а не проверка личности преподавателя. Создать учебную сессию может любой посетитель.
- Fingerprint и GPS дают мягкую защиту. Возможны совпадения и подмена; преподаватель разрешает спорные случаи вручную.
- Ручное добавление возможно только в активную неистёкшую сессию. После закрытия журнал остаётся доступен для чтения и выгрузки.
- Расписание вынесено в настройки. В материалах видны часы последних пар, но полного подтверждённого списка нет: текущие часы не выдаются за официальное расписание ЧГУ.
- QR генерируется по endpoint из `qr_path`, а не хранится отдельным PNG на диске.
- Личные кабинеты, приложение ЧГУ и семестровая статистика оставлены возможными улучшениями.

Выбор корпуса заменяет ввод координат преподавателем. Геозона хранится в сессии как снимок точки из серверного справочника; источники и ограничения точности — в [CAMPUSES.md](CAMPUSES.md).
