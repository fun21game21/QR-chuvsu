# Корпуса ЧГУ и координаты

Координаты взяты из точек карточек Google Maps (`!3d` / `!4d`), а не из центра видимой карты (`@`). Исключение — корпус З: поиск Google Maps выдавал соседний Б, поэтому использована точка карточки 2ГИС, а ссылка Google Maps открывает эту координату. Геолокация студентов этим сервисам не передаётся: приложение считает расстояние локально на backend.

Это точки зданий, а не границы аудиторий. Г, И и К используют общую точку одного главного здания. Для II используется общая точка соединённого комплекса; отдельная точка II не подтверждена. Для Л и П адресные карточки Google имеют неполные подписи; корпус определяется по официальному адресу. Эти особенности нужно учитывать при выборе радиуса. Точки частично проверены физически на местности.

## Обновление справочника

Файл: `backend/app/campuses.json`. Значения проверяются Pydantic при запуске. ID должен быть уникальным и стабильным. Для правки адреса/точки измените запись, обновите этот документ и пересоберите backend: `docker compose up --build -d --wait`.

Форма отправляет только `campus_id`. Сервер берёт адрес и координаты из справочника и сохраняет их в `sessions`. Существующие занятия сохраняют свои координаты после изменения справочника. Миграция `002_session_campus.sql` добавляет nullable `campus_id`, поэтому прежние занятия остаются доступны. Не подменяйте неподтверждённые точки случайными координатами.
